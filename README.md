# 🐟 大鱼吃小鱼

一个纯 HTML5 Canvas 的「大鱼吃小鱼」休闲小游戏，单文件、零依赖，浏览器打开即玩。

> 🌐 **在线试玩**：https://keabao2025.github.io/big-fish-game/

## 玩法

- 🖱️ **移动鼠标 / 手指滑动**控制你的小鱼
- 🐟 吃掉**比自己小**的鱼来长大
- ⚠️ 躲开**比自己大**的鱼，被碰到会掉一条命
- 🍙 吃掉 **米粒 / 饭团 / 大盘饭** 也能快速长大
- 🐚 躲开 **藤壶**，碰到会**减速**你
- 🔥 连续进食触发**连击加分**

## 两种模式

| 模式 | 规则 |
|------|------|
| **普通模式** | 三条命 |
| **挑战模式** | 一条命，按战绩触发三种插图结局 |

## 特性

- 纯 HTML5 Canvas，单文件、零依赖，打开即玩
- 程序化绘制：鱼、气泡、水草、粒子、道具全部代码生成
- 玩家自定义形象 + 被寄生状态形象图片
- 吃鱼/受伤/道具/生长等各具音效，Web Audio 合成背景音乐
- 连击加分、受击无敌闪烁、最高分本地存档（localStorage）
- 绿色光圈=可吃，红色光圈=危险

## 入口

- 主文件：**`大鱼吃小鱼.html`**
- 入口页：**`index.html`**（自动跳转）
- 双击 `大鱼吃小鱼.html` 或浏览器打开即可游玩

> ⚠️ 提示：直接以 `file://` 打开可能限制 Web Audio 声音。建议通过本地静态服务器或本页面的在线地址访问，以获得完整音效体验。

## 运行

```bash
# 任意本地静态服务器
python -m http.server 8123
# 然后访问 http://localhost:8123/大鱼吃小鱼.html
```
